### Task 4: Ownership verbs — requirements / plan apply / run advance+accept

**Files:** Create `libexec/orchid-requirements`, `libexec/orchid-plan`; modify `libexec/orchid-run`, `tests/test_run.sh`; create `tests/test_ownership_verbs.sh`.

**Interfaces:**
- `orchid requirements import <file>` — epoch-fenced; copies into `.orchid/requirements.md` atomically; refuses when `run_status` is not `planning` (immutable after plan); journals `plan_revision`.
- `orchid plan apply --reason "..."` — epoch-fenced; stages + commits ALL current `.orchid/` durable changes (roadmap, tasks, context, requirements) on the INTEGRATION branch in one commit `orchid: plan apply` (works from any checkout via temp worktree of the integration branch — never switches the user's branch; mirror init's pattern); journals `plan_revision` with the reason; sets `run_status: running` when it was `planning`.
- `orchid run advance <status> --reason` — run_status transitions `planning→running→accepting→complete|blocked` validated (table in the verb); `orchid run accept --reason` = shorthand for accepting→complete, requires an acceptance evidence file argument `--evidence <path>` copied atomically to `reviews/acceptance.log`, journals kind `acceptance`.
